# PhotoMap

Первый макет карты исторических фотографий. Интерфейс собран на Vue 3, TypeScript и Tailwind CSS. Карту рисует MapLibre GL JS со светлым стилем Positron от OpenFreeMap.

## Запуск

Из папки `web`:

```sh
npm ci
npm run dev
```

Открой адрес, который покажет Vite. Для сборки запусти `npm run build`, для просмотра сборки — `npm run preview`.

## Как посмотреть макет

- Карта открывается в центре Парижа. Нажми на метку и переключай снимки по годам. В поиске по ID попробуй, например, `102` или `107`.
- Для загрузки снимка введи имя, выбери на карте объект и заполни карточку. Статус виден в личном кабинете.
- Чтобы проверить работу модерации, открой приложение в другой вкладке, войди с ролью «Модератор» и одобри снимок. Карта в первой вкладке обновится автоматически.
- Вход и роли в макете демонстрационные. Сессия хранится во вкладке, изменения снимков, звёзд и жалоб — в браузере для этого адреса. Для базовой карты нужен интернет. Архивные снимки входят в проект, их источники перечислены в [подписях к снимкам](public/photos/CREDITS.md).
